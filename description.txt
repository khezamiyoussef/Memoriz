PROJECT OVERVIEW
----------------
MomentCraft is a no-code web application for building beautiful, personalized
celebration pages — birthdays, anniversaries, Valentine's Day, and more. Users
drag and drop pre-designed templates onto a canvas, customize each section's
content, and preview the final page instantly. No login or backend required.

The project also ships with a fully pre-built hardcoded celebration site
("Maryem's Birthday 2025") that showcases the kind of page the builder can
produce, and is deployed to GitHub Pages.

--------------------------------------------------------------------------------
BUILDER — HOW IT WORKS
--------------------------------------------------------------------------------

1. User lands on the Dashboard (no login required).
2. Left panel lists all 11 templates with search and category filters.
3. User drags a template from the left panel and drops it onto the canvas.
4. The element appears as a card on the canvas (max 10 elements total).
5. Clicking an element opens the ElementEditor right panel for that element.
6. Each field (text, image, color, etc.) can be edited inline.
7. Canvas items can be reordered via drag-and-drop.
8. "Save" button persists the canvas to localStorage (key: saas_canvas_items).
9. "Preview" button opens the full-screen PreviewModal.
10. The PreviewModal routes each templateId to its matching Preview component.

Canvas constraints:
  - Maximum 10 elements
  - When 10 elements are reached, the drop zone is replaced with a styled
    "Maximum reached" banner (lock icon + message)

--------------------------------------------------------------------------------
PREVIEW COMPONENTS
--------------------------------------------------------------------------------

Each Preview component receives `values: Record<string, string>` and renders
the corresponding section with live data from the editor. They are independent
of the builder canvas and simply display what the user configured.

Special behavior:
  - PreviewMakeAWish: Shows a wish input with a sparkle animation on submit.
  - PreviewFloatingDecoration: Shows only animated hearts, no text.
  - PreviewTimeline: Renders only events that have a date or title filled in.
  - PreviewNameDisplay: Renders only meaning entries with a non-empty word.
